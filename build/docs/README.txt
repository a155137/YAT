YAT - YuXiang Analysis Tool
Version @VERSION@
Published by YX Studio

Engineering data analysis and visualization for Windows x64.


Installation
------------

None. YAT is portable: it needs no installer and no separately installed .NET.

1. Unzip YAT-v@VERSION@-win-x64.zip to any folder you can write to.
2. Run YAT.exe from that folder.

Keep every file of the folder together; YAT.exe needs the files beside it.
To remove YAT, delete the folder.


Getting started
---------------

1. YAT opens with an untitled project and an empty worksheet, Sheet1.
2. Copy a table - with a header row of column names - from Excel or a text
   file, and paste it into the worksheet (Ctrl+V).
3. Choose a graph from the Graph menu: Scatter Plot, Histogram, Box Plot,
   Probability Plot or Empirical CDF.
4. Choose the columns and options in the setup dialog, and click OK.
5. The graph opens in a window of its own. Right-click it to edit its labels,
   axes, legend, statistics, box plot options or appearance, or to copy it.
   Its File menu exports it as PNG or PowerPoint.

Save the project with File > Save (Ctrl+S) to keep the worksheet data.
Help > About YAT shows the version.
